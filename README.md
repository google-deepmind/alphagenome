The `alphagenome` package provides programmatic access to the AlphaGenome family
of models and the AlphaGenome Atlas, developed by Google DeepMind:

-   **AlphaGenome 2**: Our latest multimodal DNA sequence model, with improved
    cell-type specificity, generalization to your own human scRNA-seq data
    (expression conditioning), and imputation of unobserved modalities across 1
    Mb sequences.
-   **AlphaGenome Atlas**: Genome-wide *in silico* mutagenesis across 9 billion
    human variants, providing pre-computed variant effect scores and the
    AlphaGenome Variant Impact (AVI) score on a
    [zero-code website](https://alphagenome.google/atlas) and through the API.
-   **AlphaGenome 1**: The original model described in
    [Avsec et al. (2026)](https://www.nature.com/articles/s41586-025-10014-0).

The API is offered free of charge for
[non-commercial use](https://alphagenome.google/terms). Query rates vary with
demand: pre-computed Atlas lookups support higher query rates than live model
predictions, which suit small-scale analyses rather than large, genome-wide
analyses.

## Installation

Install `alphagenome` from [PyPI](https://pypi.org/project/alphagenome):

```bash
pip install alphagenome
```

See the [Installation guide](https://www.alphagenomedocs.com/installation.html)
for setting up a virtual environment (`venv`, `uv`, or `conda`), installing from
source, and configuring your
[AlphaGenome API key](https://alphagenome.google/api).

## Quick start

See [Getting started](https://www.alphagenomedocs.com/getting_started.html) to
choose the right tool for your task and walk through the AlphaGenome 2 and
AlphaGenome Atlas API workflows.

Explore the [documentation](https://www.alphagenomedocs.com/) for interactive
notebooks and guides:

-   [**Tutorials**](https://www.alphagenomedocs.com/tutorials/index.html):
    Step-by-step Colab notebooks covering reference conditions, making
    predictions, variant scoring, expression conditioning given your own
    scRNA-seq data, plotting, and the AlphaGenome Atlas.
-   [**User guide**](https://www.alphagenomedocs.com/user_guides/index.html):
    Conceptual guides on data objects, model metadata, imputation, variant
    scoring, visualization, and migrating from AlphaGenome 1.
-   [**Vignettes**](https://www.alphagenomedocs.com/vignettes/index.html):
    End-to-end biological analyses and case studies.
-   [**API reference**](https://www.alphagenomedocs.com/api/index.html):
    Complete Python package reference.

For example, to score a variant with AlphaGenome 2:

```python
from alphagenome.data import genome
from alphagenome.models.v2 import dna_client

dna_model = dna_client.create('YOUR_API_KEY')

# Choose a condition: CD14-positive monocytes in blood.
condition = 'UBERON:0000178_CL:0001054'

# Select a genomic region: center a 1 Mb interval on the variant.
variant = genome.Variant(
    chromosome='chr2',
    position=219243701,
    reference_bases='C',
    alternate_bases='T',
)
interval = variant.reference_interval.resize(dna_client.SEQUENCE_LENGTH_1MB)

# Score the variant across all recommended scorers and format as a DataFrame.
scores = dna_model.score_variant(
    interval=interval,
    variant=variant,
    condition=condition,
)
```
